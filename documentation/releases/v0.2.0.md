# Linea 0.2.0 — Windows release

Linea now follows local Windows media sessions instead of Spotify's Web API. Start a song in Spotify desktop or another compatible player; no Linea Spotify login or Spotify developer registration is required.

- Synced lyrics, existing lyric providers and local cache are preserved.
- Play/pause, previous/next and seek remain available where the player supports them.
- Shuffle and repeat appear when the player exposes their support and current state.
- Three lyric lines are visible by default at every text size. Saved window sizes remain.
- Click-through is removed from settings; its global shortcut still works.
- Existing themes, resizing, pinning, tray and keyboard shortcuts remain.

## Install and update

Download **Linea-0.2.0-setup.exe** below. Supports Windows 10 1809+ and Windows 11, x64. Existing Windows stable and beta installations can update to this stable version.

Windows supplies the metadata, timing and available controls, so behavior can vary by player. Browser sessions with incomplete or inaccurate metadata may provide limited lyrics or controls. Spotify login, library likes and remote-device control are no longer part of Linea.

## macOS

**There is no new Mac app in this release.** Mac playback development continues separately. The legacy [Mac 0.1.6 download](https://github.com/Meet2304/Project-Linea/releases/download/v0.1.6/Linea-0.1.6.dmg) retains the old Spotify integration and account restrictions. The latest-mac.yml asset only keeps existing Mac update checks on 0.1.6; it is not a Mac 0.2.0 build.
